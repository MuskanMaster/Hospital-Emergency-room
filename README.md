🏥 Hospital Emergency Room Dashboard

📊 About the Project

An **Excel-based Hospital Emergency Room Data Analysis and Dashboard** project developed to analyze patient attendance, demographics, waiting time, satisfaction, admissions, and department referrals.

The project transforms raw ER data into an interactive dashboard using **Excel, Power Query, Pivot Tables, and Pivot Charts**.

## 🛠️ Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Data Cleaning
* Data Visualization

## 📈 Key Analysis

* Total patient attendance
* Patient age-group analysis
* Gender and race distribution
* Admission vs. non-admission
* Patient waiting time
* Patient satisfaction
* Department referrals
* Attendance trends

## 📂 Files

* `Dashboard.xlsx` – Interactive Excel dashboard and analysis
* `Hospital Emergency Room Data.csv` – Dataset used for the project

## 🎯 Objective

To demonstrate practical **data cleaning, analysis, visualization, and dashboard development** skills using Microsoft Excel.
